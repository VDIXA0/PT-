TryHackMe – Junior Penetration Tester (PT1)

A hands-on cybersecurity learning path designed to develop practical penetration testing skills through interactive labs, guided exercises, and realistic scenarios.

It covers essential areas, including:

- Networking: TCP/IP, protocols, ports, and network fundamentals.
- Linux Fundamentals: Command-line operations and system administration.
- Information Gathering: Reconnaissance and OSINT techniques.
- Nmap: Network scanning and service enumeration.
- Web Hacking: Identifying and exploiting web application vulnerabilities.
- Burp Suite: Intercepting and analyzing HTTP requests.
- Vulnerability Assessment: Identifying security weaknesses.
- Exploitation: Understanding and exploiting vulnerabilities.
- Privilege Escalation: Linux and Windows privilege escalation.
- Active Directory: Understanding and attacking Windows domain environments.

Objective: Develop the practical knowledge and hands-on experience required to pursue entry-level penetration testing and junior offensive security roles.
