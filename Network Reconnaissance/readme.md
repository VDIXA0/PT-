# Network Reconnaissance

## Project Overview

This project focuses on practical Network Reconnaissance techniques using Kali Linux.

Network Reconnaissance is an important phase of penetration testing that involves identifying network hosts, discovering open ports, detecting running services, and collecting technical information about target systems.

The purpose of this project is to develop practical skills in network discovery, port scanning, service enumeration, and reconnaissance documentation.

## Objectives

- Understand network reconnaissance fundamentals.
- Identify active hosts within an authorized network.
- Discover open, closed, and filtered ports.
- Identify running services and their versions.
- Perform basic service enumeration.
- Understand TCP and UDP scanning techniques.
- Analyze Nmap scan results.
- Save and document technical evidence.
- Build a structured reconnaissance report.

## Tools & Technologies

- **Kali Linux** — Penetration testing environment.
- **Nmap** — Network discovery and port scanning.
- **Netcat (nc)** — Network connection testing.
- **Ping** — Basic host connectivity testing.
- **Traceroute** — Network path discovery.
- **Curl** — HTTP service interaction.

## Practical Activities

### 1. Network Discovery
Identify active hosts and understand basic network connectivity.

### 2. Port Scanning
Discover open ports and analyze their states.

### 3. Service Detection
Identify services and their versions using Nmap.

### 4. Service Enumeration
Collect additional information about discovered network services.

### 5. Network Analysis
Interpret scan results and identify potentially interesting services for further investigation.

### 6. Evidence Collection
Save scan outputs, organize findings, and document practical activities.

## Key Concepts

| Concept | Description |
|---|---|
| Host Discovery | Identifying active devices on a network |
| Port Scanning | Discovering accessible network ports |
| TCP | Connection-oriented transport protocol |
| UDP | Connectionless transport protocol |
| Service Detection | Identifying services running on open ports |
| Version Detection | Identifying software and service versions |
| Enumeration | Gathering detailed information about discovered services |
| Firewall Filtering | Understanding how filtering affects scan results |
